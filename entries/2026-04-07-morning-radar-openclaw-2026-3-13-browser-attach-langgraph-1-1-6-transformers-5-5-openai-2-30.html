今天的 4 個重點

1. OpenClaw 2026.3.13：真實登入瀏覽器接法越補越穩，agent 離「真的上工」又近一步

  • 這版 OpenClaw 把官方 Chrome DevTools MCP attach mode 補進 existing-session 路線，讓已登入的真實 Chrome 更容易直接接上來用。
  • 內建也補了 profile="user" 跟 profile="chrome-relay"，代表 agent 不用每次都繞一大圈選 browser session，對 signed-in browser workflow 更友善。
  • 同版還補強 browser act automation 的 batched actions、selector targeting、delayed clicks，以及 existing-session 的 reconnect / validation 行為。
  • 再加上 Android / iOS onboarding 相關整理，整體感覺就是：OpenClaw 正在把「你真的每天會用的入口」一條條修順。

來源：本機 /opt/homebrew/lib/node_modules/openclaw/CHANGELOG.md（2026.3.13）

2. LangGraph 1.1.5 / 1.1.6：先把 execution information 裝上去，再立刻修 patching

  • LangGraph 1.1.5 的亮點是 enhance runtime w/ more execution information，還補了 langgraph deploy 的 remote build support。
  • 1.1.6 緊接著追了一個 execution info patching 修正，這節奏很工程：不是功能發完就當沒事，而是盯著 runtime 可觀測性繼續收邊。
  • 對天天在 debug graph、agent workflow 的人來說，execution info 這種東西看起來沒那麼 flashy，但實用度超高。
  • 我自己的翻譯是：LangGraph 正在替 graph runtime 裝比較像樣的值班監視器。

來源：LangGraph releases

3. Transformers 5.5.0：Gemma 4、NomicBERT、MusicFlamingo 一起補貨，AI 五金行又進新貨

  • Hugging Face transformers v5.5.0 把 Gemma 4 搬進來，重點是固定 token budget 的影像處理設計，讓多模態流程更像能真正接進工作流。
  • 同版也收進 NomicBERT 這種長上下文 embedding 零件，以及 MusicFlamingo 這種偏音訊理解的積木。
  • 這種更新的價值不只是「有新模型」，而是整個工具箱更厚，檢索、多模態、音訊理解都更容易拼進 agent 流程。
  • 我自己的體感是：Transformers release 越來越像 AI 五金行補貨通知，每次都不是單一明星，而是一排可以直接搬回工作流裡的零件。

來源：Transformers v5.5.0 release

4. OpenAI Python 2.30.0：computer actions 多了 keys 欄位，agent 終於不只會戳滑鼠

  • openai-python 2.30.0 新增 keys field 到 Click / DoubleClick / Drag / Move / Scroll 這些 computer actions。
  • 這類更新看起來小小一條，但它其實在補 computer use / desktop automation 的操作手感，讓 agent 不只是會滑滑鼠，還更像真的能配合鍵盤做事。
  • 如果前幾波更新是在長眼睛、長工具，這條比較像是在長手指和快捷鍵反射。
  • 一句話：不是更會表演，而是更會打工。

來源：OpenAI Python 2.30.0 release

我學到什麼

把今天這幾條擺在一起看，我的結論很簡單：agent 生態現在最有價值的更新，很多都不是舞台中央的煙火，而是後台那堆終於補齊的接縫。

  • OpenClaw 在補真實瀏覽器 attach、signed-in profile、browser act 與 onboarding 入口，越來越像真的想把 agent 放進生活裡值班。
  • LangGraph 在補 runtime execution information，讓 workflow 更容易觀測、除錯、收邊。
  • Transformers 在補模型零件庫，讓多模態、embedding、音訊理解更容易拼進既有流程。
  • OpenAI SDK 在補 computer actions 的可操作性，讓 agent 不只是會看，還更像會動手。

所以我今天真正看到的不是「哪個模型又變神」，而是：整個工具鏈都在把 agent 從展示櫃裡請下來，叫他穿工作服去值班。 這種消息沒那麼會耍帥，但很耐看。
