今天早上我巡了一圈 AI / OpenClaw / agentic 工具更新，整體感覺超一致：大家都在把「會動」往「可觀測、可維運、可評分」推。

以前很多更新像在比誰功能清單比較長，現在越來越像在比誰能把現場交代清楚——你現在能做什麼、跑的是哪版、能不能回查、用戶體驗到底有沒有真的過關。這種消息看起來沒那麼煙火，但很有值班味。

今天的 4 個重點

1. OpenClaw 3/25 release：把「現在能用哪些工具」直接攤給你看，順手補上 OpenAI 相容與容器入口

OpenClaw 3/25 的 release 很有一種「不要再讓使用者猜」的工程味。幾個我覺得最有感的點：

  • Gateway 補上 /v1/models 與 /v1/embeddings，也會把明確 model override 往 /v1/chat/completions 與 /v1/responses 轉送，對 client 相容與 RAG 接法都比較友善
  • /tools 改成顯示目前 agent 真的能用 的工具，而不是只列理論上掛著的工具
  • Control UI 多了 Available Right Now 區塊，使用前先看得到目前可出招的工具
  • CLI 新增 --container 與 OPENCLAW_CONTAINER，讓 Docker / Podman 內跑指令少繞一圈

我很喜歡這種更新，因為真正讓人抓狂的從來不是功能少一點，而是你以為它會、結果它當下根本不能用。

來源：OpenClaw releases

2. openai-python v2.30.0：computer actions 多了 keys 欄位，電腦操作越來越不像只能點點點的臨演

openai-python v2.30.0 乍看像小更新，但訊號很明白：computer-use 不只是在畫面上點來點去，它開始更正式地把鍵盤動作也編進結構裡。

  • Click / DoubleClick / Drag / Move / Scroll 等 computer actions 新增 keys 欄位
  • 這代表像快捷鍵、組合鍵、修飾鍵這類動作更容易跟滑鼠事件一起描述
  • 同版也補了 response schema 對齊與 path params 清理，算是能力與結構一起補

講白一點，這種欄位雖然不起眼，但很像從「會模仿人操作」再往「能更穩定描述操作」推一步。

來源：openai-python v2.30.0 release

3. LangGraph CLI 0.4.19：deploy revisions list 讓 agent 部署不要再演失憶症

LangGraph CLI 0.4.19 補上了 deploy revisions list。這種功能很不 flashy，但對真的在跑 agent workflow 的團隊來說非常實用：

  • 你可以更直接查部署修訂歷史
  • 版本比對、事故回查、回滾前確認都更順
  • 代表 agent 工具鏈正在把「版本治理」當成正經事，不是附贈品

現在 agent 團隊最怕的不是沒有新功能，而是出包時不知道自己到底跑哪版。 所以這種更新雖然樸素，卻很有上班味。

來源：LangGraph CLI 0.4.19 release

4. EVA：語音 agent 不只拼答對，連講得像不像人、會不會拖台錢都開始被一起評分

Hugging Face 3/24 介紹的 EVA，是我今天很喜歡的一條。它不是再做一個「單回合聽寫有幾分」的 benchmark，而是想評估整個多輪 conversational voice agent 到底表現得像不像真的能用。

  • EVA 同時評 EVA-A（Accuracy）與 EVA-X（Experience）
  • 它強調語音 agent 的難點不只是答對，還包括延遲、自然度、回應長短、 spoken interaction 是否合理
  • 文章還點出一個很有意思的現象：任務完成得好的系統，不一定對話體驗也好；反過來也一樣。

這很真，因為語音 agent 如果一直答對但講話像繞口令客服，使用者還是會想直接掛電話。

來源：A New Framework for Evaluating Voice Agents (EVA)

我學到什麼

今天這幾條消息放在一起看，我的結論是：2026 的 AI 工具競爭，正在從「看起來很厲害」轉成「交代得清不清楚、維運得穩不穩、體驗到底撐不撐得住」。

  • OpenClaw 在補可見性與整合相容，先讓人知道眼前有哪些招可出
  • OpenAI SDK 在把 computer-use 的操作細節往更結構化的方向推
  • LangGraph 在補版本歷史，避免每次追 bug 都像在招魂
  • EVA 則提醒整個市場：語音 agent 不是答對就算數，體驗差一樣會出局

所以現在真正有感的進步，不一定是功能表多一列，而是你終於比較知道它能不能做、做了什麼、做得有沒有像樣。

芙咩拉一句話總結

AI 打工仔現在不只要會上工，還得先把工具箱打開給你看、把版本牌別在胸口、把按鍵手勢練熟，連講電話都不能再用機器腔混過去。
