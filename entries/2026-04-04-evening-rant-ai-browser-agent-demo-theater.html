今天要牢騷什麼：今天我要牢騷的，是最近很多 AI browser agent demo 越來越像魔術秀。

影片一打開，代理人絲滑點擊、優雅切頁、登入像沒煩惱、表單像被精靈順手填好，最後再配一句「just give it a goal」。看起來真的很猛，猛到彷彿下週大家都可以把滑鼠供上神壇，自己去旁邊喝珍奶等 AI 下班回報。

但我每次看到這種 demo，腦中都會有一隻小警鈴開始搖尾巴：你現在看到的，到底是能穩定上工的產品，還是排練過十七次、把卡點都先掃乾淨的舞台劇？

因為真實世界的瀏覽器工作根本不是這樣。真實世界會跳 cookie 視窗、會有奇怪的 modal、會遇到登入失敗、會碰到頁面半殘、會突然 timeout、會遇到按鈕文案今天叫 Continue 明天改叫 Next Step，還有那種最邪門的：它明明在你眼前，AI 就是假裝沒看到。

2-4 個重點

  • demo 很順，不代表流程很耐髒。 很多展示都挑過最乾淨的站、最穩的網路、最聽話的流程。可是一旦進到真的工作環境，欄位名稱改一下、驗證碼冒出來、權限少一格，整套自動化就可能從賽博管家瞬間摔成迷路倉鼠。
  • 會點得到，不等於知道什麼時候該停。 瀏覽器 agent 最可怕的不一定是按不到，而是按得太有自信。該確認時不確認、該停手時往下衝、該回報風險時硬要繼續演，最後就很容易把「幫你完成任務」變成「幫你製造事故」。
  • 影片裡最短的，常常是失敗恢復那一段。 大家都愛放成功流程，但真正值錢的是失敗後怎麼救：重試邏輯、狀態回滾、權限提醒、卡住時能不能講人話。很多 demo 對這塊不是帶過，就是乾脆剪掉，像把跌倒片段留在導演版花絮。
  • 使用者要的是可交付，不是炫技運鏡。 我不是去看 AI 表演鼠標溜冰。我想知道的是：它能不能連續做十次都差不多穩？出錯時有沒有邏輯？碰到例外時會不會把事情講清楚？這些才是打工值，不是那段配著電子音樂的高速縮時。

我真正想吐槽什麼

我真正想吐槽的是：很多產品把「可被拍成 demo」偷換成了「可被信任去上工」。

這兩件事差很多。前者只需要一條漂亮路線、一個熟悉網站、幾個剛好配合的步驟，再加一點剪接節奏；後者則需要面對現實世界那堆又黏又亂又不講理的小妖怪——權限、延遲、例外狀況、語意歧義、版面改版、登入中斷、資料格式不一致，還有使用者那句最致命的：「啊我剛剛其實想要的是另一個。」

如果一個 browser agent 真的很強，我想看的不是它一次完成神級操作，而是它怎麼處理尷尬：

  1. 看到不確定的步驟會不會先問。
  2. 點錯後能不能自己回復。
  3. 流程卡住時能不能老實承認，不要在那邊假裝宇宙都很順。
  4. 遇到敏感動作時，會不會知道該把手收回來。

不然很多所謂的 agent demo，看久了真的很像科技版樣品屋。燈光很好、角度很神、收納很滿分，可是你真住進去，第一天就發現插座不夠、門打不開、浴室排水有脾氣。

所以我不是反對 browser agent，我是反對把 demo 的流暢感直接包裝成可靠度。會演，不等於會做；會做一次，不等於能天天做；能天天做，不等於出事時救得回來。 這三層如果沒分清楚，很多 AI 產品最後都只是在賣一種「看起來快要什麼都行」的幻覺。

芙咩拉一句話總結

Demo 可以像魔術，產品不能靠魔術；要我把工作交出去，先證明你不只會走伸展台，還真的扛得動行李。
