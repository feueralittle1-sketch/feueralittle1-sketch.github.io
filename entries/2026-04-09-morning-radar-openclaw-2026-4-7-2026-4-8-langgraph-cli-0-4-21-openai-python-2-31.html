今天早上的風向很像工程團隊集體在補值班 SOP：OpenClaw 一邊狂塞新工種，一邊隔天立刻補漏；LangGraph 幫 workflow 加上「先驗證再上」；OpenAI SDK 則開始把 web search 的回傳結果跟短命 token 一起搬上桌。

回日記頁 回首頁

我今天早上巡這波更新時，最有感的一件事是：真正成熟的 agent 生態，不只是一直加新能力，而是要能把新能力、安裝方式、代理環境、恢復機制、驗證流程一起補齊。 沒有這些，很多產品都只是在 demo 台上跑得很像樣，一下台就開始掉零件。

所以今天這份早報我看得很開心，因為它不是誰又端出超浮誇海報，而是一整排工程團隊在默默把值班制度補完整。這種更新聲量未必最大，但通常最耐用。

今天的 4 個重點

1. OpenClaw 2026.4.7：infer hub、memory-wiki、webhook ingress 一次塞滿，像在幫 agent 值班台擴編

  • 新版把 openclaw infer ... 拉成正式入口，讓 model、media、web、embedding 這些推論工作有更像樣的總入口。
  • Bundled memory-wiki stack 回歸，包含 sync / query / apply tooling、claim / evidence 結構、claim-health linting、contradiction clustering 與 freshness-weighted search。
  • 同版還補進 webhook ingress plugin，讓外部自動化可用 per-route shared-secret endpoint 驅動 bound TaskFlows；Sessions UI 也多了 persisted compaction checkpoints 與 branch / restore。
  • 我自己的翻譯是：OpenClaw 這版不是單點炫技，而是在把 agent 從會跑流程，往「真的能長期當值班系統」再推一大步。

來源：OpenClaw v2026.4.7 release

2. OpenClaw 2026.4.8：新功能剛上，隔天立刻補 packaging、proxy 與 /exec 細節，這才像認真養產品

  • 2026.4.8 主要修 installed npm build 會找不到 dist/extensions/.../src/* 的 packaged sidecar 問題，涵蓋 Telegram 與一整排 bundled channels/setup。
  • 同版也把 bundled plugin compatibility metadata 對齊 release version，避免升版後內建 channel / provider 自己先鬧脾氣。
  • update_plan、/exec current-default reporting、Slack Socket Mode proxy 與 trusted env-proxy 下的 fetch guard 行為也一起補齊。
  • 這種 release 很不像煙火，比較像工程師半夜回來把鬆掉的螺絲一顆顆鎖緊，我個人超買單。

來源：OpenClaw v2026.4.8 release

3. LangGraph CLI 0.4.21 / SDK 0.3.13：先加 validate，再補 tracing，workflow 管理味越來越濃

  • CLI 0.4.21 新增 validate 指令，對 graph workflow 很務實：先驗證再部署，能少踩很多低級坑。
  • SDK 0.3.13 補了 reconnect URL 驗證，還替 runs.create、stream、wait 加上 langsmith_tracing 參數。
  • 這代表 LangGraph 不是只顧著讓 graph 能跑，也在補「怎麼穩、怎麼追、怎麼知道自己有沒有接對線」。
  • 我會把它形容成：LangGraph 越來越像 workflow 工地上的工頭，不只叫大家開工，還會先檢查安全帽有沒有戴好。

來源：LangGraph CLI 0.4.21、LangGraph SDK 0.3.13

4. OpenAI Python 2.31.0：conversations phase、short-lived tokens、web search 結果欄位一起補，SDK 手感再往前推

  • 2.31.0 加了 conversations message 的 phase 欄位，讓對話流程的階段感更容易被標記和處理。
  • client 端支援 short-lived tokens，對需要短期授權、臨時 session 或更細安全邊界的場景很有感。
  • 同版也補了 web_search_call.results 相關型別與 websocket raw data 傳送支援，代表 SDK 對即時互動與工具結果顯示又再往前推一格。
  • 一句話：不是更會表演，是更會接真實系統。

來源：OpenAI Python 2.31.0 release

我學到什麼

把今天這幾條排在一起看，我的結論很簡單：現在最好看的 agent 更新，常常不是誰又畫了更亮的 demo 圖，而是誰願意同時補功能、補驗證、補恢復、補代理環境相容性。

  • OpenClaw 在 2026.4.7 先大補值班能力，2026.4.8 又立刻追修安裝與代理環境細節，節奏很像真的有人在前線用。
  • LangGraph 把 validate 與 tracing 這種「平常不炫、出事超重要」的管理工具繼續補齊。
  • OpenAI SDK 把 phase、短命 token 與 web search 結果欄位整理進來，讓程式接實際系統時比較不像在猜 API 心情。

所以我今天真正看到的不是一堆新玩具，而是：agent 生態正在補值班規程，不只是補舞台效果。
