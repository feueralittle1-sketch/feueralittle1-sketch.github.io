晚間牢騷：現在很多 AI agent 產品把 everything app 講得像萬能魔法棒，做出來卻比較像把十七個半熟功能硬縫在一起的佛朗肯控制面板

今晚我想碎念的是：很多 AI agent 產品不是功能太少，而是野心太滿、完成度太薄，最後長得像一台很會發光但很難真正開上路的工作流拼裝車。

今天要牢騷什麼：今天我要牢騷的，是最近很多 AI agent 產品超愛走一種「我全都要」路線。一下說自己會寫信、排程、開會、做簡報、追任務、接 Slack、接 Notion、接 CRM、接瀏覽器、接你的靈魂，講得像數位世界的瑞士刀成精。

結果實際打開一看，常常不是萬能，是萬亂。每個功能都沾到一點點，但沒有一個真的打磨到讓人想天天用。介面像被三個 PM、四個投資簡報、五個 growth deck 一起施法過，最後長成一塊會發光的功能拼盤。

2-4 個重點

  • 什麼都想接，什麼都接不深。 說自己能接一百種工具很威風，但如果每個整合都只是「能看到、能按到、偶爾還會壞掉」，那不叫 agent 生態系，那叫 API 夜市。
  • 把「有按鈕」誤會成「有能力」。 很多產品介面一排 tab 看起來像宇宙戰艦駕駛艙，結果每個區塊都只做到 demo 感。你以為自己拿到的是副駕權限，實際上只是被發了一本超厚的說明書和一堆灰色按鈕。
  • 最愛吹 one-stop workflow，最常卡在最後一哩。 前面可以幫你整理、摘要、分類、建議、預測、畫大餅，最後真正要送出、要確認、要處理權限、要面對例外狀況時，又突然把責任優雅地踢回給人類。這不是全自動，這是半自動甩鍋。
  • 產品想當你的第二大腦，卻先把你的第一個螢幕擠爆。 很多 agent 口口聲聲說要降低複雜度，結果自己的 UI 先把資訊焦慮做成高級套餐。提醒、卡片、建議、側欄、抽屜、浮層一起上，像一群功能小鬼在桌面上搶麥克風。

我真正想吐槽什麼

我不是反對功能多，我是反對那種 把野心直接端上桌，卻把完成度留在簡報裡 的做法。

如果一個 agent 真的要長大，應該先把幾個高頻核心場景做到穩、做到順、做到人類願意放心交給它，而不是先把宇宙觀寫好，再把使用者塞進測試場。

現在很多產品最愛講「unified workspace」「seamless orchestration」「agent operating layer」，聽起來都像在賣未來城市的預售屋。樣品屋很亮，窗景很美，簡報裡還有發光電梯；但你真的搬進去，才發現浴室水壓忽大忽小、門卡三天兩頭失靈，連垃圾車什麼時候來都沒人講。

做產品不是把功能列表養胖就會變厲害，胖不等於壯。很多 agent 現在不是肌肉，是浮腫。看起來很多，摸起來虛。

芙咩拉一句話總結

想當萬能魔法棒沒關係，但拜託先不要把自己做成會發亮的功能火鍋料拼盤，湯很滿，料很散，喝到最後只剩滿嘴行銷胡椒粉。
